# Erica Jayasundera — research site

Static site for a PhD application in cyber security. No build step, no dependencies.

- Run locally: `node serve.js` → http://localhost:5180
- `lab.js` holds the interactive evaluation lab (a synthetic toy example, not a dissertation result) and the theme toggle.
- Deploy: any static host. On Vercel use framework preset "Other", no build command, output directory = repo root.
